## 상품 카드

- 그리드: **데스크톱 4열 × 3행 = 페이지당 12개**
- → 구현: 이미지는 `object-contain`(패스 묶음 이미지가 잘리지 않도록), 카테고리는 DB에 `pass`/`single`로 저장하고 화면에서 패스/단품으로 표시
- 카드: 연한 테두리 박스 안 이미지(세로형 표지 또는 패스 묶음) → 카테고리(회색 작게, "단품"/"패스") → 상품명("2026 Hidden Kice 시즌7") → 가격
  - 할인 없음: "40,000원" (굵게)
  - 할인 있음: 원가 취소선 "76,000원"(회색) / "5%"(주황) + "64,800원"(굵게)
- **데이터 불일치:** 76,000원의 5%는 72,200원인데 Figma는 64,800원 → 할인가를 계산하지 않고 `original_price`, `price`, `discount_rate`를 데이터로 저장해 그대로 표시
- 배지 없음

## 계획 변경 (PRD §1: Figma/원문 우선)

1. **정렬 → 카테고리 필터(전체/패스/단품).** 화면에 가격 정렬이 없고 원문이 "화면에 보이는 부분 위주"라고 함. `selectProducts(list, q, category)`로 바꾸고 `category` 컬럼은 필수(`'pass' | 'single'`, 화면 표기 패스/단품)
2. **페이지네이션은 만든다.** PAGE_SIZE=12, 검색어나 카테고리가 바뀌면 1페이지로
3. 스키마: `title`, `category`, `image_url`, `price`(판매가), `original_price`(nullable), `discount_rate`(nullable), `created_at`
4. 반응형 열 수 (Figma에 모바일 없음 → 직접 정함): 375px 2열 · 768px 3열 · 1280px 4열
